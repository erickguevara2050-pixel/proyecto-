# Midterm Project – Part 2
## Reactive Controller Competition in F1Tenth

---

### Project Overview

As part of the Autonomous Vehicles course, students will develop a practical project using the official F1Tenth simulator.
Each student is required to individually implement a reactive controller based on the Follow the Gap algorithm, which will be tested in a competitive group environment.

### Project Objective

The main objective of this project is to evaluate the implementation and performance of autonomous navigation algorithms in simulated environments, reinforcing the theoretical and practical concepts acquired throughout the course.
